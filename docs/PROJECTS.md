# Project inventory

The Master coordinates independent projects through their project workers. The public documentation intentionally omits private paths, account identifiers, and chat identifiers.

| Project role | Primary responsibility |
|---|---|
| Dashboard project | Reporting and dashboard work |
| Ontology project | Data modeling and semantic-agent work |
| AI project | Application, API, and repository work |
| Master project | Cross-project coordination and durable state |

Project availability and permissions must be reconciled with the host application before dispatching work.
