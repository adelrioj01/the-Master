# The Master

The Master is a durable coordination framework for organizing work across multiple AI-assisted software projects.

## Purpose

- Route work to the correct project worker.
- Preserve decisions, handoffs, and verified status.
- Use bounded tasks and appropriate model effort.
- Keep project boundaries and approval controls explicit.

## Repository map

- `AGENTS.md` — coordination instructions.
- `GOALS.md` — objectives and scope.
- `PLANS.md` — implementation phases.
- `docs/` — operating, usage, project, and cleanup guidance.
- `state/` — compact registry and decisions.
- `handoffs/` — handoff template.

The public version intentionally omits private paths, account identifiers, chat identifiers, and live usage data.
