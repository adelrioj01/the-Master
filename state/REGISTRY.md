# Work registry

This public registry omits private paths, chat identifiers, live usage values, and account details.

| Project role | Lifecycle | Model tier | Next action |
|---|---|---|---|
| Master coordinator | active | Efficient/balanced as needed | Maintain durable state and verify worker outcomes |
| Dashboard project | review complete | Efficient | Confirm source artifact and validate layout and metrics |
| Ontology project | research complete | Efficient research tier | Export metadata for core tables; use read-only profiling only if necessary |
| AI project | deployment review complete | Balanced technical tier | Use the deployment checklist and verify staging before credential migration |

## Registry rules

- Verify live status before acting.
- Keep only concise operational state.
- Preserve private identifiers locally.
- Link a sanitized handoff when work moves between workers.
- Never store credentials, secret values, or transcripts.
