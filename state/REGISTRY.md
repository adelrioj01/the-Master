# Work registry

This public registry is a template. Live project names, paths, chat identifiers, usage values, and worker status are intentionally omitted.

| Project role | Lifecycle | Next action |
|---|---|---|
| Master coordinator | active | Reconcile workers and durable state |
| Dashboard project | review | Capture verified findings and next milestone |
| Ontology project | review | Profile source data before modeling |
| AI project | review | Capture repository findings and next milestone |

## Registry rules

- Verify status against the host application before acting.
- Keep only concise operational state.
- Link a handoff when work moves to a fresh worker.
- Never store secrets, credentials, private identifiers, or transcripts.
